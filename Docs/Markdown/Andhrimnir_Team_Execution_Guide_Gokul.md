# Andhrimnir Team Execution Guide Gokul

## Andhrímnir – Team Execution Guide
Gokul (Cloud, DevOps, CI/CD, Deployment & Monitoring Engineer)

Purpose
This execution guide defines Gokul's responsibilities, deliverables, technical knowledge, phase completion criteria, and ownership throughout the Andhrímnir AI Incident Intelligence Platform project. Gokul is responsible for ensuring the application is deployable, secure, reliable, and production-ready.
